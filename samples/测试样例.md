# md-viewer 渲染测试

这是一个 **测试文档**，用来验证渲染效果。支持 *斜体*、`行内代码`、[链接](https://example.com)。

## 代码高亮

```python
def greet(name: str) -> str:
    """带高亮的代码块"""
    return f"你好, {name}!"

print(greet("ECho"))
```
